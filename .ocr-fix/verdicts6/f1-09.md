1. **换行**：`.prettierrc.json` 的 `endOfLine` 已被（非本分片）从 `auto` 改成 `lf`，导致工作树里 CRLF 的源文件一律被 `prettier --check` 判为不合规。本分片把自己改动的 4 个 CRLF 文件（with-app-store.ts / with-store.ts / builtin.ts / timeTravelPlugin.ts）统一转成 LF 后检查通过；其余仍为 CRLF 的文件（如 offline.ts、Store.ts）未动，需要主会话在全库统一一次。
2. **NEEDS-MAIN（R6-105 尾巴）**：`userStoreKey`（及只在内部用的 `ensureAppLifecycleHooks`）是否补进 `src/integrations/enterprise/index.ts` 与 `src/integrations/index.ts` 的具名导出清单——这两个文件本分片禁改。若选「不导出」，请把这行契约写进 docs/API.md：持久化键 = store name = `user-store-` + userId，前缀是对外契约。
3. **NEEDS-MAIN（R6-106 尾巴）**：`exposeStoreAPI` 对实例上 6 个调试键的同名覆盖无告警（`src/integrations/utils.ts`，属他分片）。若要两侧口径齐平，建议在 utils.ts 里按 `bindActions` 的做法补一条「宿主已有成员 X 将被 store 调试 API 覆盖，卸载时恢复原值」告警。
